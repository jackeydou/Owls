## Features

- A new full-screen welcome on first run, with interactive owls. It walks you through two steps: connect your coding agents, then pick who runs the Router. If you skip it, a setup card stays on the thread page until something is configured.

## Bug Fixes

- Claude Code, Codex, and Cursor now find CLIs installed with Homebrew or a version manager, such as gh and node, when Owlto is opened from Finder.
- A Claude Code worker no longer sends back an empty report after its session resumes; its real reply now reaches the Router.
