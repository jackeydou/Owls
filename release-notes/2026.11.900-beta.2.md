## Before You Install

- Owls now needs macOS 13 or later.
- Owls 2026.11.900-beta.1 does not update itself, so download this version from GitHub Releases. From this version on, Owls updates itself.

## Features

- Owls checks for updates in the background and installs them on restart. Choose the stable or beta channel in Settings > Updates. Most updates download only what changed instead of the whole app.
- Each project has its own settings: its name and description, the branch and remote its worktrees use, whether to delete pushed branches when a worker is removed, and extra instructions for workers, such as code review and pull request preferences.
- The add button opens a menu to open a folder, clone a GitHub repository, or Quick start an empty project, with recent projects below.
- Every sidebar resizes by dragging. Sidebar actions show their highlight and shortcuts only on hover, and Projects move to a right-hand sidebar opened from the title bar.
- Settings has a larger page title and roomier rows.
- File pickers start from your home folder instead of Downloads.
