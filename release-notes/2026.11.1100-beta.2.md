## Features

- Router replies and worker activity show pixel-art owl avatars, one each for the Router, Claude Code, and Codex.
- When an update has downloaded, a popup in the bottom-right corner offers to restart into it. You can hide it.

## Improvements

- The light theme uses a pure white main area and a near-white sidebar instead of light gray.
- Select dropdowns in Settings have an inset chevron and a styled menu with a checkmark.
