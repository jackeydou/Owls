## Features

- Workers can use a browser. Claude Code workers use Claude in Chrome, and Codex and Cursor workers get a browser tool that runs Playwright scripts in a Chrome window. Turn it off in Settings; read-only workers never get it.
- The Router and workers can save text to your Notes.
- The left sidebar has a new Projects page that lists the Workspace and every project as cards, with quick access to each project's settings and an Add project button.
- Overview project nodes no longer show an Open conversation button. Double-click a node or press Enter to open its conversation.
