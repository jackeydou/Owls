## Before You Install

- This version starts with a fresh database. Threads, projects, settings, and memories from earlier versions, including 2026.11.900 betas, are not carried over, so Owls opens as on a fresh install. Set up the Router and add your projects again after updating.

## Features

- Each project can show an initial, an emoji, or an image as its icon, in a color you choose. The icon appears in the Projects sidebar, Settings, and the map.
- Every app icon now uses one consistent outline style, and New thread shows a plus.

## Bug Fixes

- Clicking a menu choice no longer leaves a focus ring on the button that opened it.
