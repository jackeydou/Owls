## Before You Install

- If Remote Router's relay was already on before this update, open Settings → Devices and turn on "Keep this Mac awake on power" yourself. Only turning the relay on from now on switches it on for you.

## Features

- Threads: pin threads to a Pinned section and rename them from a right-click menu in the sidebar or by double-clicking the title. Archive moved into the same menu.
- Notes: the Router and workers can edit an existing note with a new edit_note tool, changing its title, tags, or text, instead of only adding new notes.

## Bug Fixes

- Remote Router: the phone reconnects to the Mac over the relay more reliably after the Mac sleeps, naps in the background, or changes networks. Turning the relay on also keeps the Mac awake on power.
