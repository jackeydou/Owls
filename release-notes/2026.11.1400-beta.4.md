## Features

- You can message a worker straight from its panel. The input supports Markdown, pasted images, and attached files, and works with Claude Code, Codex, and Cursor workers.
- The Workspace now shows under Projects and on the map with its tasks. A Workspace folder can become its own project and be merged back later, and its past tasks, pull requests, and token usage move with it.
- Mermaid code blocks in messages and notes now render as diagrams, with a code view and copy button. If a diagram cannot be drawn, the code shows instead.
- Workers the Router sends out now show as one quiet line each, with animated dots while they run.

## Bug Fixes

- Markdown tables in messages show their row lines again, and code blocks put the language label above the code.
