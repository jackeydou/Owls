## Before You Install

- This is an early beta of the new Owls. It needs Codex or Claude Code installed and signed in on your Mac.
- It starts with a fresh database. Threads, tasks, and settings from Owls 2026.9.801 and earlier, or from Pichu, are not carried over, and macOS permissions must be granted again.
- Automatic updates are not available in this version. Download later versions from GitHub Releases.

## Features

- Talk to one Router instead of managing tasks. It sends work to your locally installed Codex or Claude Code as workers, follows up with them, and summarizes their reports. Pick what runs the Router and the workers in the first-run guide or in Settings.
- Workers that change code each get their own git worktree and `owls/<worker>` branch, kept in `~/Owls/worktrees`, so several can work at once without touching your checkout. Codex workers commit to their branch without asking for approval, while your repository's hooks and config stay protected.
- See every project and worker on one map with Cmd+J. Open a worker's details, answer its approvals, or message it directly with @.
- Threads are global. Start one with Command-N, send work to any project from it, and forward a message or a worker's result to another thread to continue from there.
- The sidebar lists each project's active workers.
- Worker panels show the pull request and CI checks for a worker's branch after you connect GitHub through the Owls GitHub app, the gh CLI, or a personal access token.
- Owls remembers your preferences and project knowledge from past threads and uses them in new ones. Review, edit, pin, delete, and export memories in the new Memory tab in Settings. Expired memories are archived on their own.
- A new owl logo, with Line, Solid, and Brow styles for the Dock and in-app icon.
- A compact title bar and a full-window Settings with tabs on the left.

## Bug Fixes

- Long Router conversations reuse the model provider's prompt cache instead of resending their full context.
- The Codex Router ends its turn after dispatching work instead of polling for results.
- Workers that share one checkout wait for each other, even across threads.
- The sidebar toggle works while the sidebar is hidden.
