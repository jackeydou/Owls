## Features

- Pichu is now Owls, with refreshed app and menu bar icons. Your existing data and integrations are preserved.
- Sign in with your OpenAI subscription to select models and use GPT Image 2 without a separate API key.
- Connect local and remote MCP servers from Customize settings, with OAuth sign-in for servers that support it.
- Explore token and message usage through daily heatmaps, model rankings, and bar or line charts.
- Install signed, notarized macOS releases from GitHub and choose stable or beta updates in General settings.
