## Before You Install

- The in-app Owlto Browser is new in this beta and replaces the separate Chrome window workers used before. Sign-ins from that Chrome window do not carry over, so sign in again in the Owlto Browser panel when a worker asks.
- Claude in Chrome now defaults off for Claude Code workers, which use Owlto's browser instead. Turn it back on in the Claude Code settings on the Workers page if you prefer it.

## Features

- Browser: workers now browse in an Owlto Browser panel in the right sidebar. Tabs show which worker drives them, sign-ins persist, and you can take over a tab and hand it back. Google Chrome is no longer needed.
- Browser: a worker can hand a tab to you for a sign-in or captcha and wait, with a notification. Each worker's downloads go to its own folder. Settings → Browser adds site rules (allow, ask, block), asking before forms are submitted on signed-in sites, clearing sign-ins, and the downloads folder.
- App icon: the default macOS and iOS app icon is now the Huddle cream owl.

## Bug Fixes

- Router: while a connected agent is still starting at launch, the Router's owl shows a loading ring instead of flashing the setup notice.
