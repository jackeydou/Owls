## Features

- A new Automation page lets you schedule tasks to run hourly, daily, on weekdays, weekly, or monthly. The Router and workers can also set up their own scheduled follow-ups.
- When a worker opens a pull request, failing checks, change requests, merge conflicts, and new comments on it now go back to that worker. Turn this on from the Pull requests page.
- Folding in a Router thread now collapses everything the Router did between two of your messages as one block.

## Bug Fixes

- Hover the Router avatar to show the fold toggle. Message actions now sit to the right of the text instead of covering it.
- Selecting text in a message shows Copy, Forward, and Save as note for just the selection.
