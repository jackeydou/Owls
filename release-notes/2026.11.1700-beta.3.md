## Before You Install

- After this update, Owlto checks the stable update channel by default. There is no stable release yet, so to keep getting beta updates, open Settings → Updates, click the device ID at the bottom five times, and pick Beta.

## Features

- Every worker now runs at the permission level set in Settings instead of one the Router picks, and read-only Codex and Cursor workers can use Owlto's browser tool.
- Settings → Updates shows this device's ID at the bottom of the page. The update channel picker is hidden behind it.
- The worker panel message box placeholder now reads "Do anything."
