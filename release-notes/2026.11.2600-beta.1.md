## Features

- iOS app: a new Notes tab shows the notes your Mac syncs to iCloud once iCloud sync is on. You can edit them and write new ones, and the Files app shows the Owlto folder too.
- iOS app: pick System, Light, or Dark in Settings, and start a new thread in one tap.

## Bug Fixes

- Mac app: iCloud Drive now shows the Owlto folder, a second copy of Owlto no longer opens, and macOS asks for local network access for Remote Router.
- Usage: Claude Code shows "Signed out" when the CLI has no login and "Could not read usage" when the read fails, instead of saying the account has no plan limits.
