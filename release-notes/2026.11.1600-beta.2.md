## Features

- Pick a project's icon from an emoji picker with search, or upload an image. For a non-square image, drag the frame to choose which part to keep. Colors now live in the same picker.
- A worker's report lists its files and links as numbered references. Files open with a click, and links ask before they open.

## Bug Fixes

- Choosing a Cursor model in a project's settings no longer fails with "This request is invalid".
