## Features

- Run worker tasks with your local Cursor CLI. Set it up on the new Settings → Cursor page.
- An Open in button in the worker panel opens the worker's folder in an installed editor, Finder, or terminal, such as VS Code, Cursor, Zed, Xcode, JetBrains IDEs, or Ghostty. It shows each app's icon and remembers your last choice.
- Tasks that don't belong to a project run in a workspace folder, ~/Owls/Workspace by default, which you can change in Settings.

## Improvements

- Every button shows that it was pressed. Buttons that start work show a spinner, and actions like Check for updates or Export confirm the result.
- Markdown links in chat are blue. Clicking one opens a small menu with Copy link and Open, and Cmd-click opens it directly.

## Bug Fixes

- Inputs, buttons, and links no longer get a thick black outline when focused. Keyboard focus uses a soft themed ring.
- Going back to the conversation from the Overview no longer makes the map flash.
