## Features

- A new Feedback button in the title bar files bug reports, feedback, and feature requests as GitHub issues. It posts as your connected GitHub account, or opens a prefilled issue page in your browser.
- Long Router replies now fold to their first four lines. Use the toggle under the Router avatar to expand or collapse them.
- Agents settings use shorter copy. The account button shows whether an agent is connected, and you can now disconnect a connected agent. It stays disconnected across restarts until you connect it again.
