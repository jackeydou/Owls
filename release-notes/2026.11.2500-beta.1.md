## Features

- Notes (experimental): turn on iCloud sync in Settings → Experiments to keep your notes in iCloud Drive, so your Macs and iPhone share them. Turning it off copies the notes back to this Mac.
- Right sidebar: every tab now shares one width. It only changes when you drag it, and it is remembered across restarts.
- iOS app: messages render Markdown, including headings, lists, task lists, code blocks with a copy button, quotes, tables, and links.

## Bug Fixes

- Notes: a note in a synced folder that has not downloaded yet stays in the list and on its boards, and conflict copies keep the same id on every device.
