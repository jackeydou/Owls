## Before You Install

- This build sends anonymous usage data (installs, launches, feature use) to help improve Owlto. It never sends your messages, code, or files. You can turn it off in Settings → Updates.

## Features

- Owlto now connects only the coding agents you choose. It detects which agent CLIs are installed and shows Not detected for missing ones. Agents you already had connected stay connected.
- The window opens maximized on first launch and remembers its size, position, and maximized state across restarts and updates.
