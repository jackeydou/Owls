## Features

- A new Usage entry in the sidebar shows how much of each coding agent's plan is left, such as the Claude Code and Codex 5-hour and weekly limits, extra usage, and credits. If an agent can't report its usage, it says why.
- You can edit the Router's instructions under Settings → Router & Workers, and restore the default with one click.

## Improvements

- Cards are organized by tag instead of by project. The Cards sidebar is replaced by top-bar menus for tags, boards, and search.

## Bug Fixes

- The Projects sidebar's open and close button sits on the sidebar and stays available in every view, including Cards.
