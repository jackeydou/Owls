## Before You Install

- Notes are now stored as Markdown files. Notes saved in earlier versions are not carried over, so copy anything you want to keep before updating.

## Features

- A new Doodle style, matching the Owlto website, in light and dark. Switch it in Settings > Appearance.
- The app logo row in Settings shows your current logo with a Change button that opens a picker.
- Each note is a Markdown file in ~/Owlto/Notes. Edit it in any app and the change shows up in Owlto right away.
