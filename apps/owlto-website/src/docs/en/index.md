Owlto is a free, open-source macOS app that runs your local coding agents as one team. You describe the work to the **Router**. It plans the work and hands each part to a **worker**: a Claude Code, Codex, or Cursor session on your Mac. Each worker that edits code works on its own git branch, and you decide what to merge.

## Start here

New to Owlto? Read these three pages in order:

1. [Install Owlto](/docs/install/): system requirements, download, and updates.
2. [Connect coding agents](/docs/connect-agents/): which agents can run the Router and the workers, and how to connect them.
3. [Your first task](/docs/quickstart/): one request from start to finish, including reviewing and merging the result.

## How the docs are organized

- **Get started** pages take you from a fresh Mac to a finished first task.
- **Guides** cover one job each: running work across projects, steering workers and answering approvals, and reviewing and merging results.
- **Concepts** explain how the Router, workers, projects, and worktrees fit together, and what Owlto does and does not do for you.
- **Reference and help** lists keyboard shortcuts and fixes for common problems.
