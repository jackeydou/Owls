## App

| Shortcut | Action |
| --- | --- |
| `⌘N` | New thread |
| `⌘J` | Open the Overview map. Press again to go back. |
| `⌘K` | Open your notes. Press again to go back. |
| `⌘,` | Open Settings |
| `⌘B` | Show or hide the sidebar |
| `⌥⌘B` | Show or hide the right sidebar |
| `⌘O` | Open a folder as a project |
| `Esc` | Back out one level: Settings, then the details panel, then the map |

## Message boxes

| Shortcut | Where | Action |
| --- | --- | --- |
| `⌘↵` | Thread | Send to the Router |
| `Enter` | Thread | New line |
| `Enter` | Worker panel | Send to the worker |
| `Shift+Enter` | Worker panel | New line |
| `@` | Thread | Mention a worker, a note, or a project |
| `Backspace` | Thread, empty box | Stop addressing a mentioned worker |

## The @ menu

| Shortcut | Action |
| --- | --- |
| `↑` `↓` | Move through suggestions |
| `Enter` or `Tab` | Pick a suggestion |
| `Esc` | Close the menu |

## Overview map

These work when no text field has focus.

| Shortcut | Action |
| --- | --- |
| Arrow keys | Move between cards |
| `Enter` | Open the focused card |
| `F` | Reset the view |
| `N` | Jump to the next worker waiting on you |

## Elsewhere

| Shortcut | Action |
| --- | --- |
| `←` `→` | Switch tabs in Settings |
| `⌘`-click | Open a link directly |
