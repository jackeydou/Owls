大部分来回沟通由协调者（Router）处理，但你随时可以亲自和任何 Worker 对话，而且每个超出 Worker 权限的请求都由你决定。

## 直接和 Worker 对话

有两种方式：

- **在对话里**：输入 `@` 并选择 Worker。输入框会显示你正在对哪个 Worker 说话，消息直接发给这个 Worker，不经过协调者。在空输入框里按 `Backspace`，就会改回发给协调者。
- **在 Worker 面板里**：点击 Worker 卡片，在面板的输入框里输入。按 `Enter` 发送，`Shift+Enter` 换行。

无论哪种方式，协调者下次查看对话时都会看到你的消息。消息支持 Markdown、粘贴图片，以及最多 8 个、每个不超过 20 MB 的文件。

## Worker 忙碌时发消息

Worker 正在进行一轮工作时，发送按钮会变成**加入队列**。排队的消息会在这一轮结束时发送。对每条排队的消息，你还可以：

- **Steer**（Claude Code 和 Codex）：把消息插入正在进行的这一轮，让 Worker 立刻看到。
- **打断并发送**（Cursor）：停止当前这一轮，用你的消息开始新的一轮。
- **立即发送**：Worker 空闲时可用。
- **移出队列**。

停止 Worker 会清空它的消息队列。

## 处理批准请求

Worker 在做权限不允许的事之前会先问你。请求会出现在三个地方：

- 对话输入框上方的托盘：“*智能体* 需要你处理”，附带**查看上下文**，以及其他待处理请求的数量。
- Worker 自己的对话里。
- 全景地图上该 Worker 的卡片。在地图上按 `N` 可以跳到下一个等你处理的 Worker。

权限请求选择**仅本次允许**或**拒绝**；提问或计划确认选择**继续**或**取消**。协调者不能替你批准任何操作。

没有“始终允许”选项。想减少请求，可以在**设置 → 协调者与 Worker → Worker** 中提高该智能体的权限：

- **只读**：Worker 可以读取和搜索。
- **工作区访问**（默认）：Worker 可以修改任务文件夹里的文件，超出范围前会先问你。
- **完全访问**：Worker 在其智能体允许的范围内自行操作。

## 停止或移除 Worker

- **停止 Worker**：结束当前这一轮。worktree 和分支都会保留，你可以审阅它做了什么，或者再给它发消息。
- **移除 Worker**：把它从对话中移除，并清理它的 worktree。分支上的提交会保留，有未提交改动的 worktree 也会保留。见[审阅并合并 Worker 的结果](/docs/review-and-merge/#清理-worktree-和分支)。
