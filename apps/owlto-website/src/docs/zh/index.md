Owlto 是一款免费开源的 macOS 应用，把你本机的编程智能体组织成一支团队。你把需求告诉**协调者（Router）**，它负责规划，并把每一部分交给一个 **Worker**：你 Mac 上的一个 Claude Code、Codex 或 Cursor 会话。每个改代码的 Worker 都在自己的 git 分支上工作，合并哪些由你决定。

> **提示：** Owlto 中文界面把 Router 称为“协调者”。本文档沿用应用里的叫法，界面名称以中文界面为准。

## 从这里开始

第一次使用？按顺序阅读这三页：

1. [安装 Owlto](/docs/install/)：系统要求、下载和更新。
2. [连接编程智能体](/docs/connect-agents/)：哪些智能体能运行协调者和 Worker，以及如何连接。
3. [完成第一个任务](/docs/quickstart/)：从提需求到审阅、合并结果，完整走一遍。

## 文档结构

- **入门**：从一台全新的 Mac 到完成第一个任务。
