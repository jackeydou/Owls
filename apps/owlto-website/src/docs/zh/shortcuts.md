## 应用

| 快捷键 | 操作 |
| --- | --- |
| `⌘N` | 新建对话 |
| `⌘J` | 打开全景地图，再按一次返回 |
| `⌘K` | 打开笔记，再按一次返回 |
| `⌘,` | 打开设置 |
| `⌘B` | 显示或隐藏侧栏 |
| `⌥⌘B` | 显示或隐藏右侧栏 |
| `⌘O` | 打开文件夹作为项目 |
| `Esc` | 返回上一层：设置，然后详情面板，然后地图 |

## 输入框

| 快捷键 | 位置 | 操作 |
| --- | --- | --- |
| `⌘↵` | 对话 | 发送给协调者 |
| `Enter` | 对话 | 换行 |
| `Enter` | Worker 面板 | 发送给 Worker |
| `Shift+Enter` | Worker 面板 | 换行 |
| `@` | 对话 | 提到某个 Worker、笔记或项目 |
| `Backspace` | 对话，输入框为空时 | 取消发给所提到的 Worker |

## @ 菜单

| 快捷键 | 操作 |
| --- | --- |
| `↑` `↓` | 在候选项之间移动 |
| `Enter` 或 `Tab` | 选择候选项 |
| `Esc` | 关闭菜单 |

## 全景地图

以下快捷键在没有文本框获得焦点时生效。

| 快捷键 | 操作 |
| --- | --- |
| 方向键 | 在卡片之间移动 |
| `Enter` | 打开当前卡片 |
| `F` | 重置视图 |
| `N` | 跳到下一个等你处理的 Worker |

## 其他

| 快捷键 | 操作 |
| --- | --- |
| `←` `→` | 在设置中切换标签页 |
| `⌘`-点击 | 直接打开链接 |
