Owlto 的设计原则是让你的工作留在你的 Mac 上。你的项目、代码、对话和消息都保存在你的 Mac 上，从不发送给我们。本政策说明少量会离开你设备的数据是什么、由谁接收，以及你有哪些选择。

本政策适用于：

- **Owlto Mac 版**，即桌面应用。
- **Owlto iPhone 与 iPad 版**，与 Mac 配对使用的应用（远程 Router）。
- **Owlto 中继**（`relay.owlto.dev`），通过互联网连接你的手机和 Mac。
- **本网站** `owlto.dev`。

Owlto 由 Owlto 开发者开发。关于本政策的问题请发送至 [support@owlto.dev](mailto:support@owlto.dev)。

## 简要说明

- 我们不出售你的数据，不展示广告，也不跨其他公司的应用或网站追踪你。
- 你的项目、代码、对话和消息留在你的 Mac 上。手机与 Mac 之间的连接是端到端加密的，连我们的中继也无法读取。
- iPhone 与 iPad 版没有统计分析、不需要账号，也没有追踪。
- Mac 版会发送匿名使用统计，帮助我们了解哪些功能被使用。你可以随时关闭。
- 中继只保留连接设备所需的最少信息；如果你登录使用中继，还会保留你的 GitHub 用户名。

## Owlto Mac 版

**你的工作留在本地。** 项目、对话、Worker 输出、笔记和设置都保存在你 Mac 上的 Owlto 数据文件夹中。我们没有接收这些内容的服务器。

**编程智能体和模型服务商。** Owlto 运行你自己安装并登录的编程智能体，例如 Claude Code、Codex 和 Cursor；如果你为内置 Router 引擎配置了模型服务商，也会调用它。你发给这些智能体的内容（包括提示词和代码）会按各自的条款和隐私政策发送给相应公司。Owlto 不会复制你在这些服务上的密码或登录令牌。

**匿名使用数据。** 正式版会向统计分析服务 PostHog 发送匿名使用事件，帮助我们了解哪些功能被使用，并进行功能实验。此功能默认开启，你可以在 **设置 → 更新 → 发送匿名使用数据** 中关闭。关闭后不会发送任何数据。

- 事件记录的是操作，例如"打开应用""新建对话""发送消息""启动 Worker""添加项目"或"连接智能体"。
- 每个事件带有一个在你 Mac 上随机生成、不关联任何账号的安装 ID，以及应用版本、macOS 版本、处理器类型、应用语言和已连接的智能体种类。
- 事件从不包含消息文本、代码、文件名、路径、项目名称或任何你输入的内容。
- PostHog 会在每次请求中收到你的 IP 地址，并可能用它估算大致位置，例如国家或城市。

**GitHub。** 如果你连接了 GitHub 账号，令牌保存在你的 Mac 上，只用于代表你访问 GitHub，例如克隆仓库或提交反馈。

**反馈。** 你在应用中发送的反馈会作为 Owlto 公开 GitHub 仓库中的 issue 提交：要么以你的 GitHub 账号发布，要么打开预填好的页面由你自己提交。你写的内容是公开的。如果你选择附带诊断信息，会附上应用版本、macOS 版本、处理器类型和 Electron 版本。

**更新。** 应用会检查 GitHub Releases 是否有新版本。GitHub 会收到来自你 Mac 的普通网络请求，其中包括你的 IP 地址。

## Owlto iPhone 与 iPad 版

手机应用是你 Mac 的遥控器。所有数据都在 Mac 上，所有 Worker 也都在 Mac 上运行。手机只显示 Mac 发来的内容，关闭后不保留对话。

- **没有统计分析或追踪。** 应用不包含任何统计分析、广告或追踪代码，使用时也不需要账号。
- **保存在设备上的数据。** 已配对 Mac 的列表（名称和地址）、这些配对的加密密钥（保存在 iOS 钥匙串中）以及你的风格设置。删除应用即会一并删除。
- **相机。** 仅用于扫描 Mac 上显示的配对二维码。相机画面不会被保存或发送到任何地方。
- **本地网络。** 用于在你的网络中或通过 Tailscale 等 VPN 直接连接你的 Mac。
- **照片和文件。** 只读取你选择附加的照片和文件，并加密发送到你的 Mac。
- **通知。** 如果你允许通知，手机的推送令牌会提供给已配对的 Mac。Mac 用只有你手机持有的密钥封装每条通知，再通过中继发送到 Apple 推送通知服务。中继和 Apple 都无法读取通知内容。Apple 按其自身的隐私政策处理推送令牌和投递。

## Owlto 中继

当手机和 Mac 不在同一网络时，中继让手机能够连到 Mac。中继运行在 Cloudflare 上，只有你在 Mac 应用中开启互联网连接时才会使用。

**中继看不到的内容。** 手机和 Mac 之间的所有内容都是端到端加密的。中继只转发加密数据，无法读取你的消息、对话、代码、文件或通知。配对码从不经过中继。

**中继处理和保留的内容：**

- **账号。** 开启中继需要在 Mac 上用 GitHub 登录。中继向 GitHub 确认你的身份后即丢弃 GitHub 令牌，只保留哈希后的账号 ID、你的 GitHub 用户名、你有几台 Mac 和几个登录会话，以及账号的创建时间和最近使用时间。登录会话只以哈希形式保存，180 天不使用即失效。
- **连接。** 每台 Mac 的信箱和每台已配对设备的哈希密钥，确保只有你的设备能够连接。
- **离线消息。** Mac 不在线时，手机可以给它留下加密消息。Mac 取走后即删除，最长保留 7 天。
- **通知。** 中继把封装后的通知转发给 Apple，不保存推送令牌。
- **网络数据。** 和所有互联网服务一样，中继能看到 IP 地址、连接时间和传输数据的大小。IP 地址用于限流和防滥用，不会写入我们的记录。Cloudflare 可能按其自身政策保留有限的请求日志。

一台 Mac 如果 30 天没有连接，它的信箱和排队消息会被自动删除。你可以在 Mac 应用的设备设置中退出中继登录或移除某台 Mac，访问会立即被切断。

## 本网站

`owlto.dev` 是静态网站，不设置 Cookie，也不使用任何统计分析或广告脚本。你选择的浅色或深色主题保存在浏览器的本地存储中，不会离开你的设备。网站由 Cloudflare 提供服务，Cloudflare 会处理请求（包括 IP 地址）以提供页面并防止滥用。

## 数据接收方

我们只与运行 Owlto 所需的服务共享数据，且仅用于上述目的：

| 服务 | 用途 | 数据 |
| --- | --- | --- |
| Cloudflare | 托管中继和网站 | IP 地址、加密的中继流量、上述中继账号记录 |
| PostHog | Mac 版的匿名使用数据 | 安装 ID、使用事件、IP 地址 |
| Apple | 向手机投递通知 | 推送令牌、封装后的通知 |
| GitHub | 中继登录、反馈、更新以及你连接的功能 | 如上所述 |

我们不出售或出租个人信息，也不为广告目的共享个人信息。法律要求时，我们可能会披露信息。

## 你的选择和权利

- 在 Mac 应用中关闭使用数据：**设置 → 更新 → 发送匿名使用数据**。
- 在 Mac 应用的设备设置中取消手机配对、退出中继登录或移除某台 Mac。
- 删除手机应用即可删除它在手机上保存的所有内容。
- 发送邮件至 [support@owlto.dev](mailto:support@owlto.dev)，询问我们保存了哪些与你有关的信息，或要求删除你的中继账号记录。根据你所在地区的法律，你可能有权访问、更正、删除你的个人数据或反对对其的处理；我们会响应这些请求。

## 数据存储位置

我们的服务商可能在美国以及其运营的其他国家和地区处理数据。跨境传输依赖服务商提供的保护措施。

## 儿童

Owlto 是开发者工具，不面向 13 岁以下儿童。我们不会在知情的情况下收集儿童的个人信息。
